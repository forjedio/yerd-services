# Redis (<= 7.2) — upstream license

SPDX-License-Identifier: BSD-3-Clause

The `redis` service slot ships Valkey on Linux/macOS and REDIS on Windows, where Valkey
has no native build. The Windows leg is built from vanilla Redis source (see the Windows
provenance table in README.md); this is that upstream Redis core license, taken verbatim
from the 7.2.15 source tree's COPYING.

Redis 7.2 is the newest BSD-3-Clause release: 7.4-7.8 moved to RSALv2/SSPLv1 and 8.0+
added AGPLv3 to that pair, so the Windows leg is pinned at <= 7.2.x for redistribution.

The artifact also stages this file as its top-level LICENSE, copied from the exact source
tree that was built. Notices for the permissive dependencies statically linked into
redis-server.exe are in redis-windows-third-party-NOTICES.txt; the LGPLv3 terms for the
bundled MSYS2 runtime DLLs are in msys2-runtime-LGPL-3.0.txt.
